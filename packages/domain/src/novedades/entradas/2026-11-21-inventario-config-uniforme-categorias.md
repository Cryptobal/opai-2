En **Configuración › Operación › Inventario** puedes definir las **prendas del uniforme** con un editor de lista (agregar, renombrar y desactivar) en lugar del JSON en Personas. Si cambias el nombre de una prenda, se conserva su clave para no perder las tallas de las fichas ni los tipos de ropa ligados.

También puedes agregar **categorías de tipos** propias de tu empresa; cada una elige si se comporta como activo (por unidad) o como ropa (por talla). Si no defines categorías, siguen vigentes Activo y Ropa.
