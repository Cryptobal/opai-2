En **Configuración › Agentes**, cada API key muestra dos avisos nuevos cuando corresponde:

- **Hereda todos los permisos**: la key puede hacer todo lo que puede su responsable.
- **No vence**: la key no tiene fecha de vencimiento.

Conviene revocarlas y crear una nueva con solo los permisos necesarios y fecha de vencimiento.
