# CAR-390 · «Tus accesos» sin «No encontrado»

- **Entró:** las páginas 404 («No encontrado», con o sin portal) no se guardan como recientes y las ya guardadas en el navegador se ocultan al leer (`apps/web/app/_components/use-recientes.ts`). Prueba en `apps/web/test/recientes-no-encontrado.test.ts`.
- **Pendiente:** nada.
- **Riesgo:** ninguno; si una página real se titulara «No encontrado» tampoco quedaría en recientes.
