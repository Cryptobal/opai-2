## Qué entra (parte 1)

- Al crear una llave de tipo usuario se eligen permisos o se pide `heredarPermisos: true`; la herencia completa deja de ser el valor por defecto (pantalla, API y MCP: la misma capacidad).
- Toda llave nueva vence: por defecto a 90 días; el máximo lo fija la empresa con el ajuste `core.apikeys_vida_maxima_dias` (1–365, sin migración). Las de scope `platform` siguen en 7 días.
- En producción, el scope `*` solo lo crea un owner.
- El formulario de Configuración › Agentes trae «Heredar permisos del responsable» apagado.

## Qué queda pendiente (parte 2)

- La pantalla marca las llaves existentes que heredan todo o no vencen.

## Decisiones nocturnas / de criterio

- «Fuera de producción» se lee como `NODE_ENV !== "production"`; test.opai.cl cuenta como producción. «Con aprobación de un owner» se lee como «la crea un owner». (revisar)
