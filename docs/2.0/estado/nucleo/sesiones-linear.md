# [Sesión Núcleo] Tabla de sesiones dueñas por proyecto de Linear

- **Qué entró:** `docs/2.0/SESIONES.md`, la tabla fija que asigna a cada proyecto de Linear de la iniciativa OPAI 2.0 · Versión 1.0 una sesión dueña, con su estado y fecha de apertura. También un enlace desde `CONTEXTO-agentes.md` § «Cómo se trabaja».
- **Qué se decidió:** una sola sesión dueña por proyecto. 04 Asistencia y 05 Instalación quedan sin sesión hasta que tengan pendientes. 06, 07, 08, 09, 11, 13, 17 y 18 tienen sesión nueva por abrir.
- **Qué queda pendiente:** cuando se abra cada sesión nueva, actualizar su fila con el estado «abierta» y la fecha de apertura.
