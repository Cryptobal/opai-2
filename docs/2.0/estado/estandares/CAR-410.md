# CAR-410 · Las brechas medias de PR ya integrados también van a Linear

- **Sesión:** Sesión Estándares
- **PR:** rama `docs/car-410-brechas-medias-a-linear`
- **Estado:** En PR
- **Migración:** No (solo documentos)

## Qué entra

- Regla nueva en `AGENTS.md` («Convenciones»), en el README de la auditoría de estándares y como adenda del ADR-106: una brecha media encontrada en un PR ya integrado queda como ticket en Linear, con prioridad normal, en el proyecto del módulo y enlazada a CAR-348. En un PR abierto basta el comentario.

## Qué se decidió

- Decisión de Carlos del 13-nov-2026 (23:10): un comentario en un PR cerrado no lo retoma nadie, así que las medias de PR integrados pasan a Linear.

## Tickets creados con esta regla (revisión del 13-nov-2026)

- CAR-408 y CAR-409 (Personas, desde #625).
- CAR-411 (Personas, desde #641).
- CAR-412 (Bancos, desde #658).
- CAR-413 (Caja, desde #639).

## Qué queda pendiente

- El lunes, la actualización semanal de la auditoría suma estas brechas al archivo de cada capa y confirma sus identificadores.
