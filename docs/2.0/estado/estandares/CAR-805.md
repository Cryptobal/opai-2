# CAR-805 · Push a main y deriva de simplicidad

## Problema

Histórico: en `main@251523276`, la medición era **3158 / 665 / 35** y `simplicidad-base.json` decía **3141 / 663 / 36** (bloqueo de `merge_group`). Tras #1129, la base en `main` quedó alineada con el árbol (hoy **3242 / 666 / 35** en `main@a0aa2a2bf`).

## Por qué el push a main no avisó

1. **Comparación en push:** con `SIMPLICIDAD_RAMA_BASE=origin/main`, `cargarBase()` lee el JSON del **mismo commit** vía `git show`. Si el archivo ya trae cifras optimistas del squash, el job compara medición contra ese JSON embebido; no revalida contra el padre. En la práctica, el hueco relevante fue el punto 2.
2. **Fast path `only_docs`:** `ci-solo-documentacion.sh` trata diff solo `*.md`, `docs/**` y **`.github/**` como documentación. El push de #1126 (solo `.github/…`) omitió gitleaks y **simplicidad**; el push de #1116 quedó **cancelado** al encolar #1126.

## Qué entra en este ticket (CAR-805)

- Push a main: sin fast path `only_docs`; `simplicidad` con `SIMPLICIDAD_BASE=local` (el JSON del commit debe igualar la medición).
- El realineamiento del JSON y `SIMPLICIDAD_BASE=local` en PR que toca la base entró con **#1129**; este PR no toca `simplicidad-base.json`.
