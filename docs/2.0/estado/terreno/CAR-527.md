# CAR-527 · Terreno con sesión explica el equipo emparejado

- **Sesión:** Sesión Cursor
- **PR:** rama `cursor/terreno-sesion-emparejado-e3f3`
- **Estado:** En PR
- **Migración:** No

## Qué entra

- Con sesión, `/terreno` deja el aviso «en construcción» y explica que Terreno se usa en el teléfono o la tablet de la instalación emparejado.
- Quien puede ver instalaciones en el ERP tiene un botón a `/instalaciones` (la ficha abre Dispositivos).
- El enlace `/terreno/emparejar` ya existía y no pide un permiso nuevo: queda para emparejar este teléfono.
- Sin sesión, el equipo emparejado sigue en el Inicio de siempre.

## Qué queda pendiente

- Nada de este ticket. No hay una vista previa de Terreno para sesiones.

## Qué se decidió

- El botón del ERP apunta a la lista de instalaciones, porque la gestión de dispositivos vive en `/instalaciones/[id]/dispositivos` y desde esta pantalla no hay una instalación elegida.
- El botón solo se muestra con portal ERP y `core:instalaciones.read`. El emparejar de este teléfono se muestra siempre: la ruta ya es pública.
