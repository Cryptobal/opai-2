# CAR-535 · Gastos recurrentes: crear fila de egreso desde la hoja

- **Sesión:** Sesión Cursor
- **PR:** #914 · rama `cursor/car-nueva-fila-recurrente-03f4`
- **Estado:** En PR
- **Migración:** No

## Qué entra

- En la hoja «Nuevo gasto recurrente», el selector «Fila del flujo» incluye **+ Nueva fila…**: pide el nombre, crea el egreso con `finanzas.filas.crear` y lo deja seleccionado.
- Enlace **Administrar filas** a Configuración › Finanzas › Flujo de caja.
- La lista permite abrir «Nuevo» aunque aún no haya filas (se crean desde la misma hoja).
- Novedad in-app y ajuste de la prueba `@preview`.

## Qué queda pendiente

- Nada de este ticket.

## Qué se decidió

- Campo inline bajo el selector para pedir el nombre (no diálogo anidado ni `prompt`), para que funcione igual en la hoja inferior del teléfono.
- Solo egresos, mismos permisos y validaciones que en el editor de configuración.
