# CAR-488 · El vínculo del banco en línea con una cartola no pierde el movimiento

- **Sesión:** Sesión Cobrar
- **PR:** rama `fix/car-488-vinculo-perdido`
- **Estado:** En PR
- **Migración:** No
- **Apilado sobre / espera:** #807 (CAR-450), que toca `sincronizar-cartola.ts`

## Qué entra

- `sincronizar-aplicar.ts`: cuando una entrega del banco en línea reconoce un movimiento que ya estaba por cartola y, al escribir, otra entrega ya le había puesto su id externo, el movimiento entrante ya no se pierde: se inserta como nuevo. Si era la misma operación, su id externo repetido lo descarta (`skipDuplicates`).
- El vínculo lleva el movimiento entrante para poder insertarlo (`sincronizar.ts`, `sincronizar-cartola.ts`).
- Prueba contra Postgres en `finanzas-banco-web4leads-db.test.ts`.

- Insertar en vez de reintentar el emparejamiento: más simple, y la base ya evita el duplicado por id externo.
