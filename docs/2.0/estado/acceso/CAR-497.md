# CAR-497 · e2e de terreno: la entrada de portería no aparecía en «En sitio»

- **Sesión:** Sesión Desempeño
- **PR:** rama `fix/car-497-porteria-e2e` (apilado sobre #854, CAR-507)
- **Estado:** En PR
- **Migración:** No

## Causa

- La portería muestra el formulario mientras todavía no sabe si «Control de acceso» está activo. El helper de la e2e (`terreno-porteria-apoyo.ts`) veía el formulario, decidía que el módulo estaba activo y registraba la entrada.
- En la empresa de pruebas el módulo `acceso` no estaba activo. El servidor rechazaba la entrada y la visita nunca llegaba a «En sitio».

## Qué entra

- `seed-pauta-e2e.ts` activa también `acceso` en la empresa de pruebas, solo en la base local de e2e.
- El helper espera la respuesta del servidor («En sitio» o «no está activo») antes de decidir si prueba la portería.

## Pendiente

- Producto: la pantalla podría no mostrar el formulario hasta saber si el módulo está activo. Hoy deja registrar sin conexión a propósito («igual puedes registrar»), así que se mantiene; queda anotado para la sesión dueña de Control de acceso.
