# CAR-424 · Borrar código sin uso del diseño clásico y de Hilo

- **Sesión:** Cursor (cloud)
- **Estado:** En PR
- **Migración:** No (la columna/tabla de preferencia de marco, si aplica, va en otro ticket)

## Qué entra

- Se borra el marco Hilo sin uso en `packages/ds` (`shell/hilo`, tokens Hilo, piel CSS `data-marco="hilo"`, clases `marco-hilo:`) y en `apps/web` (`_components/hilo/*`, `/ds/hilo`, e2e/unitarias de Hilo).
- `MarcoPortal` solo monta diseño nuevo (con empresa) o marco base (sin empresa). Ya no se lee ni se escribe `core.preferencias_marco` ni la cookie `opai_marco`.
- El catálogo de novedades sale del barrel `@opai/domain` y queda en `@opai/domain/novedades`, para que el embed no viaje en el trozo común de JS del cliente. El formato de novedades sigue en el barrel.

## Qué queda pendiente

- Retirar valores viejos de `preferencias_marco` en `core.ajuste` (migración aditiva/retirada, ticket aparte).
- Renombrar `GRILLA_KPI_HILO` / utilidades `ds-*` vacías si se quiere limpieza cosméticas (sin cambio visible).

## Decidido

- Se conserva el marco base (`AppShell` / `MarcoShell`) para Plataforma y «Sin permisos».
- Capacidades `core.hilo.*` (actividad/agenda) y el «hilo» del agente (chat) no son el diseño Hilo: se dejan.
